# PocketSDR

横屏 SDR# 风格的安卓收音机（软件定义无线电），RTL-SDR（RTL2832U + FC0013）即插即用；没有硬件也有完整仿真模式，开箱即可体验全部功能。

## 功能

### 接收
- **WFM 立体声**：19kHz 导频 PLL 立体声解码，50µs 去加重
- **RDS**：电台名（PS）、滚动文本（RT，最长 64 字符）、节目类型（PTY）；独立 IEC 62106 参考实现交叉验证位布局，SNR 7 dB 仍能解出完整台名
- **NFM**：业余电台 / 对讲机（±5kHz 频偏）
- **AM**：航空波段（118–137 MHz）
- **USB / LSB**：Hilbert 相位法单边带 + 慢速 AGC（90dB 动态范围压缩）+ 100Hz 步进——短波收听
- **HF 直接采样**：RTL2832 ADC 直收（无 tuner），HF 天线接上即可听短波

### 频谱与调谐
- 实时 FFT 频谱 + 瀑布（Bitmap 环形缓冲，~15 行/秒）
- 谱线 EMA 余晖（SDR# 风格：上升快跟/下降慢衰减）+ 峰值保持
- 频谱自动 dB 范围、dB 纵轴刻度，瀑布与频谱同刻度
- 每 MHz 网格 + 频率标签；点峰跳频、拖动平移、捏合变焦
- 模式自适应步进（WFM 100k / NFM 12.5k / AM 25k / SSB 100Hz）+ 长按连续步进

### 硬件（RTL-SDR）
- RTL2832U + FC0013 寄存器级移植（librtlsdr 同源逻辑）
- 23 档 LNA 增益（-9.9 ~ +19.7 dB）、增益自动寻优（扫 24 档选 SNR 最高）
- HF 直采、offset tuning（1/f 噪声抑制）、RTL 内部 AGC 开关
- PPM 频率校准（FC0013 晶振误差补偿）
- I2C 自动重试、tuner 探测多轮重试、失败原因分类（线的问题 / 芯片的问题）
- USB 健康/供电诊断面板；全链路日志（可一键分享）

### 收听体验
- WAV 录音（暂停/继续 + 浏览器内播放/分享/删除）；录音不受静音/静噪牵连
- 多波段自动搜台（FM/航空/业余），结果可试听、一键收藏，按强度排序
- 收藏频道（自动用 RDS 台名命名）、启动状态恢复、后台收音前台服务保活
- 一键静音（来电自动「让声中」）、新手引导、App 内 DSP 自检报告
- 仿真模式：8 个 FM 台（含立体声/RDS 台）+ 航空 AM + 2m NFM + 真实噪声底

## 使用

1. 从 [Releases](https://github.com/szkele1145/PocketSDR/releases) 下载最新 APK 安装
2. 无硬件：直接打开即仿真模式，频谱可见多个模拟电台
3. RTL-SDR：OTG 连接 → USB 权限 → 自动切换硬件（诊断面板可排障）

## 质量

每一版发布前都要过一遍 `tools\verify.ps1`（simcheck 门禁）：

- **App 内 DSP 自检**（8 项）：FFT bin 定位、抽取器阻带、FM 鉴频精度、SSB 镜像抑制、立体声分离度、音频通路、RDS 台名端到端、RDS 弱信号阈值
- **RDS 独立交叉验证**：完全独立于项目代码的 IEC 62106 参考解码器（自己的解调器/CRC/位布局），验证编码器波形符合规范——「编码解码器自洽但都错」的位布局 bug（v2.78.0 段地址错位）就是这么抓到的
- **RDS 抗噪回归**：调制度 2%~10%、载波相位 0~315°、SNR 20/15/10/7 dB 全部要求解出完整台名

夜间自主开发抓出并修复的真 bug（节选，详见 NIGHTLOG.md）：
- RDS 段地址写在 C1/C0 交通标志位上（编码解码器都错但自洽，真机上台名只会显示前 2 个字符）
- RDS 块窗口滑移后未掩 26 位，一个坏块永久错位整条位流
- RDS 位时钟整数截断，码率偏 0.28%，判决点每 460 bit 漂移 1 bit
- Gardner TED 在曼彻斯特码上退化成常量（无相位反馈）
- Biquad 极点不稳、立体声鉴相器、SSB 方向反转

## 开发

```powershell
.\build.ps1 -Task assembleDebug   # 本地构建
.\tools\simcheck\run.ps1          # 桌面 DSP/RDS 全套自检（不依赖 Android）
.\tools\verify.ps1 -Version x.y.z # 发布门禁：simcheck + APK 版本核对
.\publish.ps1 ...                 # 提交/发布到 GitHub（幂等，可安全重跑）
```
